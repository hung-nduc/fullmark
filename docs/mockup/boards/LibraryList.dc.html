quiz library list

G7: one row per quiz, sorted by name. NOTES holds the marks (source changed, ungraded; public from step 5), so the name column stays a plain name to copy. An asterisk on a score: grades pending, as on the page. Tweaks: a dark or light terminal, or --plain.

list

On a terminal: the header in bold, marks in colour, “never” and “–” dim.
